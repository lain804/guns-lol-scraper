# guns-lol-scraper

Extract account information from a guns.lol profile.

## Install

Requires Python 3.14 or newer and Git. Choose either method to make `guns-lol` available as an executable from your shell.

### [pip](https://pip.pypa.io)

```sh
python -m pip install --user git+https://github.com/lain804/guns-lol-scraper.git
```

### [uv](https://docs.astral.sh/uv/)

```sh
uv tool install git+https://github.com/lain804/guns-lol-scraper.git
uv tool update-shell
```

## Usage

```sh
guns-lol <url>
```
